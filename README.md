# Drill 08 애니메이션 뷰어

## 실행

```text
py -m pip install -r LEC08/requirements.txt
py LEC08/animation_viewer.py
```

종료: Esc 또는 창 닫기.

## 구현

- 대기, 달리기, 근접 공격, 원거리 공격의 네 동작을 순서대로 재생.
- 각 동작을 5회 반복하고 마지막 프레임에서 1초 정지한 뒤 다음 동작으로 전환.
- 모든 동작이 끝나면 처음부터 무한 반복.
- 화면 중앙에서 캐릭터를 7배 확대해 표시.
- 대기·달리기·원거리 공격은 8 FPS, 근접 공격은 10 FPS.

## 추가 구현

- 프레임마다 다른 크기를 좌표·너비·높이·기준점 정보로 처리.
- 동작별 프레임 수가 8 / 4 / 5 / 4개로 달라도 재생 가능.
