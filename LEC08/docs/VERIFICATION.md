# 검증 기록

- 환경: Linux, Python 3.12, Pico2D 1.5.1, SDL offscreen/software renderer.
- 단위 테스트 6개 통과: 실제 프레임 개수/크기, 각 애니메이션의 5회 반복 경계,
  1초 정지 경계, 마지막에서 처음으로 복귀, 큰/작은 시간 간격 일치,
  모든 프레임의 확대/화면 범위, 잘못된 입력 처리.
- 최종 이미지 높이: 364~385px / 화면 높이 600px.
- 전체 한 바퀴: 6.0 + 3.5 + 3.5 + 3.5 = 16.5초.
- 실제 Pico2D draw_scene을 0.125초 간격으로 렌더링하여 132장 캡처.
  preview.gif는 그 결과이며 합성 목업이 아님.
- 근접/원거리 공격 캡처를 육안 확인: 프레임 절단, UI 겹침 없음.
- 실제 main() 실행, 렌더링, SDL_QUIT 이벤트 처리, 정상 종료 확인.
- Windows에서는 직접 실행하지 않았으므로 해당 환경의 설치/창 동작은 미검증.
- 기존 수업 Git 저장소 및 LMS 접근 정보가 없어 원격 push/제출은 미수행.
